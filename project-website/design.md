# 网站设计风格

## 设计理念

### 视觉语言
- **海洋主题**: 深蓝色主色调，象征深海探索的神秘与专业
- **科技感**: 使用现代简约设计，突出AI技术的前沿性
- **专业性**: 清晰的信息层次，体现科研项目的严谨性

### 色彩方案
- **主色**: 深海蓝 (#1e3a8a) - 代表海洋深度和专业性
- **辅助色**: 青色 (#0891b2) - 象征技术创新和活力
- **强调色**: 橙色 (#f97316) - 用于重要信息和交互元素
- **中性色**: 浅灰 (#f8fafc) 和深灰 (#334155) - 确保良好的可读性

### 字体设计
- **标题字体**: Noto Serif SC (粗体) - 权威感和专业性
- **正文字体**: Noto Sans SC (常规) - 现代感和易读性
- **代码/数据字体**: JetBrains Mono - 技术感

## 视觉效果

### 使用的库和效果
- **Anime.js**: 流畅的页面元素动画和过渡效果
- **ECharts.js**: 专业的数据可视化图表
- **p5.js**: 创意编程效果，用于背景动画
- **matter.js**: 物理引擎，创建动态交互效果
- **pixi.js**: 高性能图形渲染，用于复杂的视觉效果
- **Splide.js**: 图像轮播和内容滑动

### 动画效果
- **页面加载**: 渐进式内容显示，从上到下依次展现
- **滚动动画**: 元素在进入视窗时触发淡入和轻微上移效果
- **悬停效果**: 按钮和卡片的3D倾斜和阴影变化
- **数据动画**: 数字计数器效果，图表数据的动态绘制

### Hero区域效果
- **背景**: 使用p5.js创建流动的粒子效果，模拟海洋流动
- **标题**: 渐变文本动画，从蓝色到青色的颜色循环
- **副标题**: 打字机效果，逐字显示项目描述

### 交互反馈
- **按钮**: 悬停时轻微放大和颜色变化
- **卡片**: 悬停时上浮和阴影增强
- **图表**: 鼠标悬停显示详细数据点信息
- **导航**: 当前页面的导航项高亮显示

### 响应式设计
- **桌面端**: 充分利用宽屏空间，多列布局
- **平板端**: 适中的内容密度，保持可读性
- **移动端**: 单列布局，大按钮和触摸友好的交互
